# Worship Leader — Weekly Checklist

Use this checklist to stay on top of everything that needs to happen before Sunday. Complete each section in Planning Center Services.

---

## Teams

- [ ] Verify all positions are filled and accepted — **Vocals, Band, and Media**.
- [ ] Send a group text to everyone scheduled that week (including the media team) with their assignment and any relevant info.

---

## Set List and Song Details

- [ ] Add your set list and plan it to fit within **20 minutes**.
  - In the **Description** field, note who is leading vocals (e.g., *Lead — Ben*) and any other important notes for the team.
  - In the **Notes** tab, add team-specific notes in the appropriate boxes (e.g., in the Audio/Visual box: *Ben leading, piano intro, on the chorus all vocal mics need to be at the same level*).

- [ ] For each song, make sure the following details are filled in. If a song is missing any of these, add them even if it's an existing song in the library:
  - **Arrangement Name** — if none exists, create one titled *IPA Arrangement*
  - **Length**
  - **BPM and Meter**
  - **Sequence** (verse, chorus, bridge, etc.)
  - **Files** — YouTube link, Apple Music link, Spotify link
  - **Lyrics and Chords**
  - **Key** (with the appropriate key label applied)

- [ ] If there is communion, add the communion song.

---

## Service Times and Notifications

- [ ] Confirm your service time is correct in Planning Center.
  - Set volunteer notifications to go out **4 days before** the service.

- [ ] Set the **Rehearsal** time (weekday or Saturday) in Planning Center.
  - Set notifications to go out **2 days before** to all teams involved.

- [ ] Set the **Sound Check** time (Sunday morning) in Planning Center.
  - Set notifications to go out **3 days before** to all teams involved.
